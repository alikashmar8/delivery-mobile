## Mobile skills

Before mobile implementation, read the matching skill under `.agents/skills/` (Codex) or `.claude/skills/` (Claude). OpenCode discovers these bundles through the root `opencode.json` skill path.

| Work | Skill |
| --- | --- |
| React Native, Expo, list/render performance, native modules | `vercel-react-native-skills` |
| Routes, stacks, tabs, links, and navigation | `expo-router` |
| Native controls, platform styling, and visual effects | `expo-native-ui` |
| Theme tokens, reusable components, and design-system audits | `expo-design-system` |
| New screen visual direction or broad UI redesign | `frontend-design` and `impeccable` |

For `@expo/ui` APIs, use the SDK 57 documentation linked from `expo-native-ui`; the source mobile skills referenced a companion `expo-ui` skill that was not included.
